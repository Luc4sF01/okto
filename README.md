# OKTO Design Agency

Site institucional da **OKTO Design Agency**, desenvolvido para apresentar a identidade da marca, o posicionamento visual e os principais canais de contato de forma clara, direta e profissional.

🔗 **Site:** https://okto-ag.com

---

## Sobre o site

O site da OKTO foi construído como uma **landing page objetiva**, priorizando impacto visual e leitura rápida.  
Não há excesso de seções ou informações: cada elemento existe por um motivo.

O foco do projeto é:

- identidade visual consistente  
- navegação intuitiva  
- hierarquia clara de informação  
- acesso rápido ao contato  .

O resultado é um site que comunica **seriedade, modernidade e presença digital sólida**, sem distrações.

---

## Estrutura

O projeto é composto por páginas estáticas bem organizadas, com atenção especial ao layout e à experiência do usuário.

Principais pontos:

- Header fixo com navegação centralizada e alinhamento preciso  
- Logo clicável funcionando como atalho para a página inicial  
- Seções bem delimitadas, com espaçamento e ritmo visual  
- Links diretos para redes sociais e WhatsApp  
- Layout escuro, limpo e elegante, focado em contraste e legibilidade  
- Animações leves aplicadas apenas para reforçar interação, nunca para poluir  

O site prioriza **clareza visual e fluidez**, não quantidade de conteúdo.

---

## Experiência e Interações

Alguns detalhes que fazem parte da experiência:

- Transições suaves em botões e links  
- Feedback visual em hover  
- Microanimações para guiar o olhar do usuário  
- Elementos animados de forma sutil com GSAP  

Tudo foi pensado para ser percebido, não para chamar atenção excessiva.

---

## Tecnologias

- HTML5 — estrutura semântica  
- Tailwind CSS — estilização utilitária e consistente  
- JavaScript — interações e comportamento  
- GSAP — animações e microinterações  
- Iconify — ícones vetoriais leves  
- GitHub Pages — hospedagem e deploy  

O site utiliza **domínio próprio com HTTPS** e atualização automática via GitHub Pages.
